# McNair Farms Inc.

A small static site for a family farm in Chase County, Nebraska. The homepage
uses responsive farm photography and a live feed to draw nearby aircraft in the
sky. When the feed is live but empty, it displays “No aircraft near the farm.”

## Public repository contents

This repository intentionally contains only the files required by GitHub Pages:
the HTML entry points, browser JavaScript and CSS, optimized images, aircraft
artwork, icons, custom-domain configuration, and license.

The private working files used to design, generate, audit, and test the artwork
are retained outside version control.

## Local preview

Serve the repository root with any static web server. Opening `index.html`
directly is not supported because the browser modules and root-relative asset
paths expect an HTTP origin.
